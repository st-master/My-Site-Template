# GitHub Pages 有効化手順ガイド

本ドキュメントは、GitHubの無料プラン（GitHub Free）で新規リポジトリからGitHub Pagesを有効化し、Webサイトとして公開するまでの手順をまとめたものです。

---

## 1. 概念と用語の整理

* **リポジトリ（Repository）**: プロジェクトのフォルダ（例: `My-Site`）。ファイルや変更履歴を管理する場所。
* **ブランチ（Branch）**: 作業の枝分かれ。`main` ブランチはプロジェクトの最新の正解データを置くメインの保存場所（幹）。
* **デプロイ（Deploy）**: 作成したWebサイトのファイルをサーバーに配置し、インターネット上で誰でも閲覧できる状態（本番公開）にすること。

---

## 2. GitHub Pages 有効化の全体の流れ

### ステップ 1: リポジトリの作成と公開（Public化）
1. GitHubでリポジトリを作成します。
2. 無料プランでPagesを利用する場合、リポジトリの可視性を **Public（公開）** に設定する必要があります。
   * **設定変更**: リポジトリの `Settings` ＞ `General` ＞ 最下部の `Danger Zone` ＞ `Change repository visibility` から `Change to public` を選択。

### ステップ 2: 初期ファイル（index.html）の作成
※リポジトリ内にファイルが1つもない状態ではブランチが選択できません。

1. リポジトリのトップページ（`https://github.com/<ユーザー名>/<リポジトリ名>`）に移動します。
2. 画面内の **「creating a new file」（新しいファイルを作成する）** をクリックします。
3. ファイル名に `index.html` と入力します。
4. ファイル内に公開したい内容（例: `<h1>Hello World</h1>`）を入力します。
5. 画面右上の **「Commit changes...」** をクリックし、変更を保存（コミット）します。これにより `main` ブランチが生成されます。

### ステップ 3: Pages のビルドとデプロイ設定
1. リポジトリの上部タブから **`Settings`（設定）** を選択します。
2. 左側メニューの **`Pages`（ページ）** を選択します。
3. **「Build and deployment」** セクションの各項目を設定します：
   * **Source**: `Deploy from a branch` を選択
   * **Branch**: `main`（または `主要`）を選択し、隣のフォルダで `/ (root)` を指定
4. **`Save`（保存）** ボタンをクリックします。

---

## 3. サイトの確認と更新

* **サイトのURL**: 
  `https://<ユーザー名>.github.io/<リポジトリ名>/`
* **反映待ち**:
  `Save` を押してから最初のデプロイ完了まで1〜2分程度かかります。画面上部に緑色の帯で「Your site is live at...」と表示されれば公開完了です。
* **ページの更新方法**:
  `index.html` や追加したファイルを編集し、**Commit changes** で保存すると、自動的に再デプロイが行われWebサイトに反映されます。
