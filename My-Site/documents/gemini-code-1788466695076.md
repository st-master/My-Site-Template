# GitHubでの動画ファイルアップロード制限と対策（作業記録）

## 1. 発生した問題
GitHub の Web ブラウザ画面から動画ファイル（`.mp4`）をドラッグ＆ドロップで追加しようとした際、ファイルサイズ制限に関するエラーが発生してアップロードできなかった。

## 2. 制限事項と原因の整理
* **Web ブラウザ（画面）からのアップロード制限:** 1ファイルあたり **最大 25 MB**
* **通常 Git コマンド（CLI）での制限:** 
  * 50 MB 超えで警告
  * **100 MB 超えで自動ブロック**
* **Git LFS (Large File Storage):** 100 MB 超〜 2 GB 以上のファイルを管理するための仕組み。

---

## 3. 試行錯誤とトラブルシューティングの経緯

### ① Git LFS の導入（一度目のアプローチ）
ブラウザ制限を回避するため、Git LFS を使用してコマンドラインから追跡・プッシュを実行。

* **発生したエラー 1:** `Not in a Git repository.`
  * **原因:** コマンドを実行した場所が Git リポジトリ内（`My-Site` フォルダ）ではなかった。
  * **対処:** `cd My-Site` でリポジトリフォルダへ移動。
* **発生したエラー 2:** `Author identity unknown`
  * **原因:** Git の初期設定（名前とメールアドレス）が未登録だった。
  * **対処:** `git config --global user.name` および `user.email` を設定。

### ② 新たな問題：GitHub Pages で動画が再生されない
Git LFS でのプッシュ自体は成功したものの、[GitHub Pages サイト](https://st-master.github.io/My-Site/videos/) 上で動画プレイヤーが黒い画面（0:00）のまま再生できない状態になった。

* **原因:** Git LFS で管理されたファイルは、リポジトリ内には実体ではなく数行のポインタテキストとして保存されるため、HTML5 の `<video>` タグが直接動画として認識・ストリーミング再生できない仕様であったため。

---

## 4. 最終的な解決手順（100MB未満の場合）
今回アップロードする動画ファイルが **1ファイルあたり 100 MB 未満** であったため、Git LFS の追跡を解除し、**通常の Git 管理ファイル** としてプッシュし直すことで正常表示・再生を達成。
