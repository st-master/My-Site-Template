Q1:  
user@smatsuda-GET MINGW64 ~/.GitHub/st-master/My-Site (master)
$ git add .
warning: adding embedded git repository: My-Site-Template
hint: You've added another git repository inside your current repository.
hint: Clones of the outer repository will not contain the contents of
hint: the embedded repository and will not know how to obtain it.
hint: If you meant to add a submodule, use:
hint:
hint:   git submodule add <url> My-Site-Template
hint:
hint: If you added this path by mistake, you can remove it from the
hint: index with:
hint:
hint:   git rm --cached My-Site-Template
hint:
hint: See "git help submodule" for more information.
hint: Disable this message with "git config set advice.addEmbeddedRepo false"

このようなメッセージが出ました

---
A1: この警告メッセージは、**「`My-Site` リポジトリの中に、別の Git 管理されたフォルダ（`My-Site-Template`）をそのまま置いた状態で `git add .` を実行した」** ために発生しています。

`git clone` などで作成した `My-Site-Template` フォルダの中に `.git` という隠しフォルダが含まれているため、Git が「リポジトリの中にリポジトリが入っている」と認識して警告を出しています。

目的（このテンプレートをどう扱いたいか）に合わせて、以下のいずれかの方法で対処するのがスムーズです。

---

**対処法 A: 単なる「実験用フォルダ」として My-Site 内で管理したい場合**

テンプレート側の `.git` 履歴を削除し、ただの普通のフォルダとして `My-Site` に含めます。

1. **インデックス（ステージング）から一旦外す**
```bash
git rm --cached My-Site-Template

```


2. **テンプレート内の `.git` フォルダを削除する**
```bash
rm -rf My-Site-Template/.git

```


3. **再度ステージングする**
```bash
git add .

```



---

**対処法 B: My-Site とは完全に別の「独立したリポジトリ」にしたい場合**

`My-Site` の中から移動させて、親リポジトリと混ぜないようにします。

1. **インデックスから外す**
```bash
git rm --cached My-Site-Template

```


2. **フォルダを `My-Site` の外へ移動する**
```bash
mv My-Site-Template ../

```


*これで `~/.GitHub/st-master/My-Site-Template` に移動し、親リポジトリと分離されます。*
