Q1:
まずは手始めに…
My-Siteのリポジトリーの複製を作ってみませんか？
---
A1:  
リポジトリの複製を作る手始めとして、既存リポジトリの複製（クローンまたはテンプレート化）の手順です。

目的に応じて以下のいずれかの方法で手軽に作成できます。

---

**方法1: コマンドライン（Git Bash）でクローンする**

ローカル環境にリポジトリをそのまま複製して、新しいリポジトリとして作成・プッシュする方法です。

* **1. ローカルに複製（クローン）**
```bash
git clone https://github.com/st-master/My-Site.git My-Site-Template
cd My-Site-Template

```


* **2. 既存の Git 履歴をリセットして新規開始する場合**
```bash
rm -rf .git
git init
git add .
git commit -m "initial commit: create site build template"

```


* **3. GitHub 上に新規作成したリポジトリへ接続してプッシュ**
```bash
git remote add origin https://github.com/<あなたのユーザー名>/<新しいリポジトリ名>.git
git branch -M main
git push -u origin main

```



---

**方法2: GitHub 上でテンプレートとして利用する（Web画面）**

今後何度もこの構造を使い回す場合に便利な方法です。

* **1.** GitHub の [[st-master/My-Site](https://github.com/st-master/My-Site)] ページ右上の **`Settings`** を開く。
* **2.** General 設定内にある **`Template repository`** にチェックを入れる。
* **3.** リポジトリ トップページに戻り、**`Use this template`** ボタンから一発で新しい複製リポジトリを作成する。

---

まずは **方法1** のように、ローカル側で `build.py` や構造を自由にいじれるテスト用リポジトリを作ってみるのがおすすめです。準備が整い次第、さっそくスクリプトの組み込みを進めていきましょう。
