### 1. `index.html` のテンプレート側（HTML）

HTML 側に、カードが繰り返し生成される領域として以下のようなコメントタグ（または Jinja2 の構文）を記述しておきます。

**`documents/index.html` (例):**

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>飲茶坊さとし - カード一覧</title>
  <link rel="stylesheet" href="../assets/style.css">
</head>
<body>
  <header>
    <h1>飲茶坊さとし カプセルコンテンツ</h1>
  </header>

  <main class="card-container">
    {% for card in cards %}
    <article class="card card-{{ card.type }}">
      <div class="card-header">
        <span class="category">{{ card.category }}</span>
        <time class="date">{{ card.date }}</time>
      </div>
      <h2><a href="{{ card.filepath }}">{{ card.title }}</a></h2>
      <div class="tags">
        {% for tag in card.tags %}
        <span class="tag">#{{ tag }}</span>
        {% endfor %}
      </div>
    </article>
    {% endfor %}
  </main>
</body>
</html>

```

### 2. `build.py` の流し込みロジック

先ほどのコードの `update_index_html` 部分を Jinja2 によるテンプレートレンダリング処理に書き換えます。

```python
import os
import glob
import subprocess
import frontmatter
from jinja2 import Template  # pip install jinja2

TARGET_DIR = "./documents"

def scan_and_parse_md(target_dir):
    cards = []
    md_files = glob.glob(os.path.join(target_dir, "**/*.md"), recursive=True)
    
    for filepath in md_files:
        try:
            post = frontmatter.load(filepath)
            meta = post.metadata
            
            card_data = {
                'type': meta.get('type', 'card'),
                'title': meta.get('title', os.path.basename(filepath).replace('.md', '')),
                'date': str(meta.get('date', '1970.0101.00')),
                'category': meta.get('category', './Fortune'),
                'tags': meta.get('tags', []),
                'filepath': os.path.basename(filepath),  # index.htmlからの相対パス
            }
            cards.append(card_data)
        except Exception as e:
            print(f"Error parsing {filepath}: {e}")
            
    # 日付降順（最新順）にソート
    cards.sort(key=lambda x: x['date'], reverse=True)
    return cards

def render_index_html(cards, template_path, output_path):
    """Jinja2テンプレートにcards配列を流し込んで index.html を出力"""
    if not os.path.exists(template_path):
        print(f"Error: テンプレートファイル {template_path} が見つかりません。")
        return

    with open(template_path, 'r', encoding='utf-8') as f:
        template_content = f.read()

    # テンプレートにデータの流し込み
    template = Template(template_content)
    rendered_html = template.render(cards=cards)

    # index.html の書き出し
    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(rendered_html)
        
    print(f"成功: {len(cards)} 件のカードデータを {output_path} に反映しました。")

if __name__ == "__main__":
    cards = scan_and_parse_md(TARGET_DIR)
    
    # テンプレートファイルと出力先ファイルの指定
    index_html_path = os.path.join(TARGET_DIR, "index.html")
    
    # HTML生成を実行
    render_index_html(cards, index_html_path, index_html_path)

```
