# OPModel（Oriented Philosophia Model）設計仕様書

本ドキュメントは、OPModel における「2次元の型・役割（プロセッサ）」と「3次元の実体（データ・フィルム）」の完全分離、およびパイプライン投影（ビルド）構造の設計と実装内容をまとめたものです。

---

## 1. コア概念・哲学

### ① 2次元世界（型・役割・プロセッサ）
- **特徴**: ディレクトリ名の頭文字を**大文字**で定義。
- **性質**: クラス・設計図・変換ロジックであり、空間や容量を持たない純粋な「役割・ベクトル」。
- **構成要素**:
  - `Structure/`: 物理構造のスキャン & セマンティックな HTML 骨格 (`<article>`) 化
  - `Parser/`: Front Matter (YAML) / 本文 (Markdown) の安全な解析 & メディア同期
  - `Template/`: HTML 全体フレームワークへの画面合成 & 投影書き出し
  - `OPModel/`: パイプラインを繋ぐ指揮者 (`build.py`)

### ② 3次元世界（実体・フィルム / Components）
- **特徴**: ディレクトリ名を**小文字**で定義。
- **性質**: 実際にファイルとして容量を占有する具体物（インスタンス/データ）。
- **構成要素**:
  - `documents/`: 記述されたドキュメント実体 (`.md`)
  - `images/`: 画像アセット (`.png`, `.jpg` など)
  - `audios/`: 音声アセット (`.mp3` など)
  - `videos/`: 動画アセット (`.mp4` など)
  - `dist/`: 最終的にスクリーンへ投影された生成物 (`.html` / アセット群)

### ③ 空点 `.` と 媒介 (Context)
- フォルダ名（`OPModel` 等）自体は相対的な原点・空点（`.`）に過ぎません。
- `relation.yaml` は、その空点（`.`）がどの 2次元 Bean を使って 3次元の実体素材をどう結びつけるかを定義する**局所的な状態記述子 (Context)** です。

4. コード実装アーカイブ
① Structure/structure_handler.py

```code

import re
from pathlib import Path

class StructureHandler:
    """カレントの空点 '.' における構造解析および HTML 骨格変換を担当する2次元 Bean"""

    def scan_context(self, base_dir="."):
        base_path = Path(base_dir)
        ignore_dirs = {
            ".git", ".vscode", "__pycache__", "dist",
            "Parser", "Design", "Structure", "Template", "OPModel"
        }
        
        detected_dirs = [
            d.name for d in base_path.iterdir() 
            if d.is_dir() and d.name not in ignore_dirs
        ]

        target_map = {
            "documents": ("content_dir", "./documents"),
            "assets": ("assets_dir", "./assets"),
            "images": ("images_dir", "./images"),
            "audios": ("audios_dir", "./audios"),
            "videos": ("videos_dir", "./videos")
        }

        components = {}
        for dir_name, (config_key, path_val) in target_map.items():
            if dir_name in detected_dirs:
                components[config_key] = path_val

        components["output_dir"] = "./dist"
        return components

    def markdown_to_html(self, md_text):
        html = md_text
        html = re.sub(r'```(.*?)\n(.*?)```', r'<pre><code>\2</code></pre>', html, flags=re.DOTALL)
        html = re.sub(r'^#### (.*?)$', r'<h4>\1</h4>', html, flags=re.MULTILINE)
        html = re.sub(r'^### (.*?)$', r'<h3>\1</h3>', html, flags=re.MULTILINE)
        html = re.sub(r'^## (.*?)$', r'<h2>\1</h2>', html, flags=re.MULTILINE)
        html = re.sub(r'^# (.*?)$', r'<h1>\1</h1>', html, flags=re.MULTILINE)
        html = re.sub(r'\*\*(.*?)\*\*', r'<strong>\1</strong>', html)
        html = re.sub(r'\*(.*?)\*', r'<em>\1</em>', html)
        html = re.sub(r'`(.*?)`', r'<code>\1</code>', html)

        lines = html.split('\n')
        in_list = False
        new_lines = []
        for line in lines:
            if re.match(r'^\s*[\-\*]\s+(.*)$', line):
                item = re.sub(r'^\s*[\-\*]\s+(.*)$', r'<li>\1</li>', line)
                if not in_list:
                    new_lines.append('<ul>')
                    in_list = True
                new_lines.append(item)
            else:
                if in_list:
                    new_lines.append('</ul>')
                    in_list = False
                new_lines.append(line)
        if in_list:
            new_lines.append('</ul>')
        html = '\n'.join(new_lines)

        paragraphs = html.split('\n\n')
        processed_p = []
        for p in paragraphs:
            p_strip = p.strip()
            if not p_strip:
                continue
            if re.match(r'^<(h[1-6]|ul|ol|li|pre|blockquote|article|section)', p_strip):
                processed_p.append(p_strip)
            else:
                processed_p.append(f'<p>{p_strip.replace("\n", "<br>")}</p>')

        return '\n'.join(processed_p)

    def build_document_structure(self, metadata, body_text):
        raw_html_body = self.markdown_to_html(body_text)
        title = metadata.get("title", "Untitled")
        date = metadata.get("date", "")
        category = metadata.get("category", "")

        structured_html = f"""<article class="op-document">
  <header class="document-header">
    <h1 class="document-title">{title}</h1>
    <div class="document-meta">
      {f'<span class="document-date">{date}</span>' if date else ''}
      {f'<span class="document-category">{category}</span>' if category else ''}
    </div>
  </header>
  <section class="document-body">
{raw_html_body}
  </section>
</article>"""

        return {
            "title": title,
            "date": date,
            "category": category,
            "structured_html": structured_html
        }
        ```
